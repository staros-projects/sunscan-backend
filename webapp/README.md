# SUNSCAN Gallery

Web app served by nginx on the SUNSCAN (`/var/www/html` → `webapp/dist`) to browse, download and delete what is stored on the device: scans, stacking, animations, snapshots.

It talks to the backend `/gallery` API (`app/gallery.py`) on port 8000 of the host that served the page, so it works through `sunscan.local` as well as through the hotspot IP.

## Development

```bash
npm install
VITE_API_URL=http://sunscan.local:8000 npm run dev   # VITE_API_URL only needed when the backend is on another host
npm run lint
```

## Production

```bash
npm run build   # writes dist/, served right away by nginx
```

`dist/` is committed: the SUNSCAN has no internet access in the field, it can't run `npm install`.

## Behaviour

- Downloads of several files or folders are zips streamed by the backend: nothing is written on the SD card. A download is capped at 10 GB (`SUNSCAN_MAX_DOWNLOAD_GB` on the backend), the size is shown before downloading and above 1 GB a confirmation is asked.
- Thumbnails are generated by the backend (JPEG, cached in `storage/tmp/thumbs`).
- Deletion: dates and scans, stacking and animation folders, snapshots. The files of a scan are not deleted one by one (the mobile app expects complete scans).
